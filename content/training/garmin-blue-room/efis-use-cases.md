# EFIS Use Cases — Garmin Blue Room

## Session Overview
Real-world EFIS installation scenarios and use cases for Garmin display products. Covers common aircraft types, typical configurations, and practical decision-making for choosing the right display solution for different customer needs.

## Key Takeaways
- Common EFIS configurations for piston singles, twins, and turboprops
- Matching customer mission requirements to the right display product
- Configuration differences between G500 TXi, G600 TXi, and G3X Touch
- Reversionary mode and backup instrument strategies
- Case studies from actual installations

## Products Covered
- Garmin G500 TXi / G600 TXi
- Garmin G3X Touch
- Garmin GI 275
