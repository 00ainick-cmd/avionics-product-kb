Almanac Data
 What is it and why do I need it?
A reduced set of data that provides
azimuth and elevation data for all of
the Space Vehicles in the GPS
constellation.
An almanac file provides spatial
location information at a given point
in time that simulators use as a
baseline. Locations are then
extrapolated, however, the longer
the timeframe, the lower the
accuracy, the less likely you are to
obtain receiver GPS lock.

GPS Overview
Spoofing – Is it all bad?
 Yes. GPS Spoofing is a term that implies a malicious attempt to trick a
GPS receiver into believing a false location. Also see GPS Jamming.
 GPS Simulation? … Good!
A testing method that uses a controlled environment to mimic real GPS
signals for evaluating GPS receiver performance, security, accuracy, and
sensitivity.

Simulation Types
Static vs. Dynamic vs. Trajectory
Static Waypoints – probably >80% of use cases
• Simulates one non-moving location’s Latitude / Longitude / Altitude
Dynamic Routes
• A series of a number of waypoints that make up a flight / travel path
Trajectory Path (can include Record / Playback capability)
• Similar to Dynamic but uses high throughput NMEA data as the input.
NMEA data is a standard protocol for information transfer. The
commands look similar to this:
$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,46.9,M,,*47
