# FAA Datacom for Your Federated Installation — Garmin Blue Room

## Session Overview
Advanced session on implementing FAA datacom capabilities in federated Garmin avionics installations. Covers data link architecture, connectivity requirements, and configuration for aircraft with distributed (non-integrated) avionics stacks.

## Key Takeaways
- FAA datacom architecture and requirements for GA aircraft
- Integrating data link capability into existing federated installations
- GDL 60 configuration for datacom services
- Connectivity between panel-mount and remote units
- Troubleshooting data link connectivity issues

- Garmin GDL 60
