# Federated EIS — Garmin Red Room

## Session Overview
Training on Garmin's federated Engine Indication System (EIS) for installations where the engine monitoring is distributed across multiple units rather than integrated into a single display. Covers wiring, probe installation, and configuration.

## Key Takeaways
- Federated vs. integrated EIS architecture
- Engine probe selection and installation for various engine types
- Wiring harness routing and connector pinouts
- EIS configuration and alarm threshold programming
- Troubleshooting erratic engine indications

## Products Covered
- Garmin G3X Touch (with EIS)
- Garmin G500 TXi / G600 TXi
