# OSPREY GPS Simulator — VIAVI Solutions

## Session Overview
Training on the VIAVI OSPREY GPS/GNSS simulator — a tool for testing GPS and WAAS receivers on the bench without requiring satellite signals. Essential for validating navigator installations before flight test.

## Key Takeaways
- OSPREY GPS simulator setup and operation
- Simulating GPS/WAAS signals for bench testing
- Testing LPV approach capability on GTN and GNS series navigators
- Creating and running test scenarios
- Verifying GPS receiver sensitivity and acquisition performance
- Using the simulator to troubleshoot navigation anomalies
